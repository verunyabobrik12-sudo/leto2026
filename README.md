## Как запустить приём заявок

Пока это не сделано, форма честно говорит туристу «позвоните нам» и не теряет его — но заявки нигде не сохраняются. Пятнадцать минут работы:

1. Создайте новую Google-таблицу (диск → Создать → Google Таблицы). Назовите, например, «Заявки — Возвращение в лето».
2. В таблице: **Расширения → Apps Script**.
3. Удалите то, что там написано, и вставьте всё содержимое файла `apps-script.gs`. Сохраните (значок дискеты).
4. Нажмите **Начать развёртывание → Новое развёртывание**. Тип — **Веб-приложение**.
   - «Запуск от имени» — **от вашего имени**;
   - «У кого есть доступ» — **у всех** (иначе заявки с сайта не дойдут).
5. Google попросит разрешения — согласитесь. Предупреждение «приложение не проверено» обходится через «Дополнительные настройки → Перейти к проекту».
6. Скопируйте выданный адрес — он выглядит как `https://script.google.com/macros/s/AKfy.../exec`.
7. Откройте `index.html`, найдите в конце файла строку:

   ```js
   var LEAD_ENDPOINT = "";
   ```

   и вставьте адрес в кавычки:

   ```js
   var LEAD_ENDPOINT = "https://script.google.com/macros/s/AKfy.../exec";
   ```

8. Проверьте: откройте страницу, отправьте тестовую заявку на своё имя. Строка должна появиться в таблице, письмо — на `ndtravel365@gmail.com`.

Почту для уведомлений можно поменять в первой строке `apps-script.gs` (переменная `NOTIFY_EMAIL`), несколько адресов пишутся через запятую.

## Как выложить на travel365.by

Сайт агентства работает на Bitrix, поэтому нужен доступ к админке или к FTP/файловому менеджеру хостинга.

1. Создайте на сервере папку, например `/leto2026/`.
2. Положите туда все `.html`-файлы, `styles.css` и всю папку `images/` целиком (структура должна сохраниться: всё лежит рядом, `images/` — рядом с `index.html`).
3. Страница откроется по адресу `travel365.by/leto2026/` — его и указывайте в рекламе.

Если доступа к хостингу к моменту запуска рекламы не будет, страницу можно за десять минут выложить на GitHub Pages и вести рекламу туда, а позже перенести на основной сайт.
